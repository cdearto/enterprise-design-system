Principles

Six principles that decide every close call.

If a component, layout, or copy choice conflicts with one of these, the principle wins.

01

Quiet by default

Color, motion, and elevation are signals — not decoration. Reserve the loud treatment for moments that need attention.

02

Tabular truth

Numbers stack vertically. Tabular-nums, right-aligned, same column width regardless of value. A misaligned digit reads as a typo.

03

One pattern, many surfaces

The bulk-action bar in the inbox is the same component in the library and the parts list. Fork the data, not the chrome.

04

Composition over invention

Build new screens by composing primitives. If you can't, the gap is the system's — file a proposal before shipping a one-off.

05

State carries meaning

Hover, active, focus, selected, disabled — never decoration. They communicate intent. Use them consistently; users learn them once.

06

Density without friction

Tight rows, compact toolbars, full-screen tables. But 32px is the floor for any interactive target. Compact never means hard to hit.
